# Роль проекта относительно DPmetaApp

**Решение автора от 10–11 ноября 2026.**

Возможный компонент ядра логического анализатора знаний, если польза подтвердится. Анализатор предполагается отдельным мобильным приложением и частью SocialMediaImage. В DPmetaApp — только при реальной пользе для разработки с ИИ; обязательным компонентом не является. Классификация файлов сама по себе не заменяет логический вывод.

Источник: [карта ролей DPmetaApp](https://github.com/dpsmpx/DPmetaApp/blob/ccr-273c59ab-oj8683/docs/direction/PROJECT_ROLES.md).

не изменяются, новый функционал не добавляется.
